# 實驗操作互動講義

> **網站**：https://bhchen66.github.io/lab-protocols/

一組可在瀏覽器直接開啟的互動式實驗講義，涵蓋巨噬細胞與肥大細胞常用的體外發炎／過敏實驗。

每份講義包含原理說明、虛擬操作流程（逐步選擇題）、數據分析練習、注意事項、專有名詞對照與參考文獻。完整清單請見網站入口頁。

## 使用說明

- 點開即用，不需安裝任何軟體，也不需註冊
- 支援深色模式，自動跟隨系統設定
- 按 `Cmd-P`（macOS）或 `Ctrl-P`（Windows）可直接列印成紙本講義，所有單元會自動展開
- 每份講義都有「專有名詞」單元，提供縮寫、英文全名與台灣繁體中文譯名對照
- 入口頁的表格可點按表頭排序，也可依細胞株分組或關鍵字搜尋

## 重要聲明

- **教學用途**：本站為教學輔助材料，實際操作請以所屬實驗室的 SOP 為準。
- **模擬數據**：頁面中所有 OD 值、螢光強度、統計圖表皆為程式即時產生的模擬數據，並標有「模擬數據」字樣，**不代表任何真實實驗結果或預期數值**。
- **文獻條件有差異**：講義列出的濃度與時間取自公開文獻，不同研究之間差異相當大，已盡量以區間而非單一數值呈現。採用前請查證原文並自行進行預實驗。
- 本站內容非醫療或診斷用途。

## 內容來源

各頁面中的數值與操作條件均標有上標編號，對應該頁最後的參考文獻清單。本站不重製文獻內容，僅整理並連結至原始出處。

## 技術說明

純靜態網站。每份講義為單一 HTML 檔，不依賴外部框架。

- 無伺服器端程式、無資料庫
- 無使用者追蹤、無 cookie、無分析工具
- **沒有任何上傳、登入或表單提交功能**——使用者在技術上無法寫入任何內容
- 字型透過 Google Fonts CDN 載入
- 以 GitHub Pages 託管
